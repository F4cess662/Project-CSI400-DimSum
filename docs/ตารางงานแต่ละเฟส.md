# ตารางงานแต่ละเฟส — ร้านนึ่งสุข (ล่าสุด)

ทุกคนทำ **ทั้ง API และหน้าเว็บ** ของงานตัวเอง · รายละเอียดเต็มอยู่ใน `docs/prompt_เขียนโค้ด/คน*.md`

**ไอคอนบอกฝั่ง**
👀 **ลูกค้าเห็น** (หน้าบ้าน) · 🧑‍💼 **พนักงานหน้าร้านใช้** · 👨‍🍳 **ครัวใช้** · ⚙️ **ผู้จัดการ/เจ้าของตั้งค่า** (หลังบ้าน) · 📊 **ดูรายงาน/ภาพรวม** · 🛠️ **ระบบ/ทีม** (ไม่มีหน้าให้ลูกค้า)
🔧 = แก้ตาม Feedback เฟส 1 · 🧩 = อยู่ใน Microservice แยก

## ใครทำฝั่งไหน (ภาพรวม)

| คน | ฝั่งหลัก | สรุปสั้น |
| --- | --- | --- |
| **1** ฐานข้อมูล + รวมระบบ | 🛠️ ⚙️ 📊 | ข้อมูลตัวอย่าง วันหยุด Log งานตามเวลา รางวัลแต้ม รายงาน วัตถุดิบ |
| **2** ผู้ใช้ + หลังบ้าน | ⚙️ 🛠️ | ล็อกอินพนักงาน จัดการพนักงาน ปิดยอดกะ **ตั้งค่าคูปอง + แบนเนอร์** notify-service ซัพพลายเออร์ |
| **3** เมนู + PM | ⚙️ 👨‍🍳 | จัดการเมนู จำนวนพร้อมขาย แผนเตรียมของ + ตรวจ/merge งานทีม |
| **4** โต๊ะ + ห้อง | 🧑‍💼 ⚙️ | ผังโต๊ะ ตั้งค่าร้าน คิว จองห้อง VIP ปรับสต็อก |
| **5** บิล + เงิน | 🧑‍💼 ⚙️ | เปิด/ย้ายโต๊ะ QR ชำระเงิน ใบเสร็จ ปิดบิลแบบสมาชิก ใบสั่งซื้อ |
| **6** ฝั่งลูกค้า | 👀 | หน้า Home เมนู QR สั่งอาหาร **หน้าสมาชิก + คูปองของฉัน** (+ สั่งแทน, รับของ) |
| **7** Dashboard + ครัว + ทดสอบ | 📊 👨‍🍳 | Dashboard กราฟ จอครัว ทดสอบ demo |

**คูปองแบ่ง 2 ฝั่ง (เหมือนเมนู):** คนที่ 2 ⚙️ **สร้าง/ตั้งค่า** คูปองหลังบ้าน → คนที่ 6 👀 **ดึงไปโชว์** ให้ลูกค้า (หน้าสมาชิก + หน้า Home) · ใช้ตารางคูปองเดียวกัน ทำพร้อมกันได้ ไม่ต้องรอ

**Microservices** (รัน `npm run dev:all`): ระบบหลัก/Gateway 3000 · 🧩 kitchen 4001 (คน 7) · 🧩 inventory 4002 (เฟส 4 ของคน 1, 2, 4, 5, 6) · 🧩 notify 4003 + คิวงาน (คน 2) · หน้าสถานะระบบ `/admin/system.html`

| **1 ฐานข้อมูล + รวมระบบ** | 🛠️ **ข้อมูลตัวอย่าง (seed)**: สมาชิก คูปอง วัตถุดิบ ซัพพลายเออร์ บิลตัวอย่าง + พนักงานตัวอย่าง 4 คน (รหัส 1234)<br>🛠️ **หน้า 404**<br>⚙️ **วันหยุดราชการ**: เลือกปี เพิ่ม/ลบวันหยุด ใช้เช็กคูปองที่ยกเว้นวันหยุด (FR-50) | 🛠️ **README + ข้อมูลทีม**: ติดต่อ, license, สมาชิกกลุ่ม + ตำแหน่ง + หน้าที่ (คน 6 ดึงไปแสดงบนเว็บ) | 📊 **ดู Log**: ใคร ทำอะไร เมื่อไหร่ กรองพนักงาน/ระดับ/วันที่ · ผู้จัดการเห็นเฉพาะงานหน้าร้าน เจ้าของเห็นทั้งหมด (UC-43, 57) | ⚙️ **งานตามเวลา**: แจกคูปองวันเกิดรายเดือน, รีเซ็ตแต้มสิ้นปี (UC-59, 61)<br>⚙️ **ตั้งค่ารางวัลแลกแต้ม**: ของฟรี/ส่วนลด (UC-41 ส่วนรางวัล) | 📊 **รายงานยอดขาย** เน้นกราฟ: แท่งรายวัน สัดส่วนวิธีชำระ Top เมนู พิมพ์ได้ (UC-42)<br>⚙️🧩 **วัตถุดิบ**: คงเหลือ จุดสั่งซื้อ ป้าย "ต้องสั่ง" ใกล้หมดแจ้งเตือนผ่านคิว (UC-45) |
| **2 ผู้ใช้ + หลังบ้าน** | 🧑‍💼 **ล็อกอินพนักงาน**: เข้าแล้วไปหน้าแรกตาม role<br>⚙️ **จัดการพนักงาน** (เจ้าของ): เพิ่ม/แก้/ปิดบัญชี role สิทธิ์รับเงิน/จอง VIP<br>🛠️ ดูแล **sidebar** ตาม role (UC-00, 51, 52) | 🧑‍💼 **ออกแบบหน้าล็อกอินใหม่**: ครึ่งจอรูปแบรนด์ ครึ่งจอฟอร์ม | 🧑‍💼 **ปิดยอดกะ**: กรอกเงินสดที่นับได้ เทียบยอดในระบบ ตรง/ขาด/เกิน + ประวัติ (UC-31) | ⚙️ **ตั้งค่าคูปอง** (หลังบ้าน): สร้าง/แก้/ปิดคูปอง ส่วนลด วัน เวลา ยกเว้นวันหยุด ยอดขั้นต่ำ + API ตรวจคูปองตอนปิดบิลให้คน 5 (UC-41 ส่วนคูปอง)<br>⚙️ **จัดการแบนเนอร์** (หลังบ้าน): อัปโหลดรูป เปิด-ปิด เรียงลำดับ<br>🛠️🧩 **notify-service**: หยิบงานจากคิวส่ง SMS/LINE **จำลอง** (บันทึกลงตาราง ไม่ส่งจริง) + 📊 หน้า **การแจ้งเตือน** | ⚙️🧩 **ซัพพลายเออร์ + ราคา**: รายชื่อร้านส่งของ ราคาต่อวัตถุดิบ เทียบเจ้าไหนถูกสุด (UC-46) |
| **3 เมนู + PM** | ⚙️ **จัดการหมวด + เมนู** (เจ้าของ): รูป ราคา หน่วย โซนครัว ล็อต · ลบ = ซ่อน<br>👨‍🍳 **เปิด/ปิดขาย**: หัวหน้าเชฟ/ผู้จัดการกดสวิตช์ (UC-53, 23) | ⚙️ **ค้นหาเมนู** "มีคำนี้อยู่" + **กรองหมวด/ราคา** + โชว์**หน่วย** ในหน้าจัดการเมนู | 👨‍🍳 **จำนวนพร้อมขาย + ล็อต**: กด +1 ล็อต หรือกรอกเอง ถึง 0 ปิดขายเอง พร้อม**หน่วย** (UC-24) | 🛠️ ไม่มีงานโค้ด · **PM** ตรวจและ merge PR | ⚙️ **แผนเตรียมของ**: ระบบแนะนำจำนวน (เฉลี่ย 4 สัปดาห์ +10%) กดยืนยัน = จำนวนพร้อมขายเริ่มต้นของวัน (UC-40) |
| **4 โต๊ะ + ห้อง** | 🧑‍💼 **ผังโต๊ะ** (หน้าแรกพนักงาน): 4 โซน โชว์ว่าง/มีลูกค้า นาทีที่นั่ง ยอด<br>⚙️ **ตั้งค่าโต๊ะ/ห้อง VIP** เพิ่ม แก้ ปิดใช้<br>⚙️ **ตั้งค่าร้าน**: เวลาเปิด-ปิด เบอร์ อีเมล ค่าห้อง VIP (ชื่อร้านดูได้อย่างเดียว) (UC-13, 54–56) | 🧑‍💼 ผังโต๊ะรองรับ**ย้ายโต๊ะ** (เลือกโต๊ะปลายทางบนผัง) | 🧑‍💼 **คิว**: ออกบัตรคิวตามขนาดกลุ่ม พิมพ์บัตร เรียก ให้นั่ง ข้าม (UC-11, 12) | 🧑‍💼 **จองห้อง VIP** (คีย์จากโทรศัพท์): ตารางห้อง × ชั่วโมง · 1–4 ชม. ≤ 15 คน pre-order ≥ 3,000฿ มัดจำ 50% · เลือกเมนูมีช่องค้นหา + หน่วย · ติ๊กรับมัดจำ (แจ้ง SMS ผ่านคิว) · มาแล้ว = เปิดบิล + ส่งครัว · ไม่มา ไม่คืนมัดจำ (UC-34–39) | ⚙️🧩 **ปรับสต็อก / ของเสีย**: นับปลายวัน บันทึกของเสีย ประวัติ (UC-50) |
| **5 บิล + เงิน** | 🧑‍💼 **เปิดโต๊ะ** → QR + สลิปพิมพ์<br>🧑‍💼 **รวมหลายโต๊ะเป็นบิลเดียว**<br>⚙️ **ยกเลิกโต๊ะ** (ผู้จัดการ ยังไม่สั่ง)<br>🧑‍💼 **หน้าบิลที่เปิดอยู่** (UC-14–16, 19) | 🧑‍💼 **ย้ายโต๊ะ** เมื่อยังไม่สั่งอาหาร QR เดิมใช้ต่อได้ | 🧑‍💼 **ชำระเงิน**: รวมหลายบิล เงินสด/พร้อมเพย์/บัตร ทอนเงิน → โต๊ะว่าง QR ใช้ไม่ได้<br>🧑‍💼 **ใบเสร็จ** แสดงหน่วย<br>⚙️ **ยกเลิกบิล (void)** ต้องใส่เหตุผล<br>📊 **ค้นบิล** ย้อนหลัง (UC-26, 30, 32, 33) | 🧑‍💼 **ปิดบิลแบบมีสมาชิก**: ค้นเบอร์/บาร์โค้ด แลกแต้ม ใช้คูปอง (1 บิล 1 ใบ) · 100฿ = 1 แต้ม · ใช้ API สมาชิกของคน 6 + API ตรวจคูปองของคน 2 (UC-27–29)<br>🧑‍💼 **หักมัดจำห้อง VIP**: ทุกบิลที่มาจากการจองห้อง VIP ไม่ว่าเป็นสมาชิกหรือไม่ (ห้อง VIP ≠ สมาชิก) | ⚙️🧩 **ใบสั่งซื้อ PO**: สร้าง แก้ตอนร่าง ราคาจากซัพพลายเออร์ ส่งแล้วคัดลอกข้อความไป LINE + แจ้งเตือนผ่านคิว (UC-47) |
| **6 ฝั่งลูกค้า** | 👀 **หน้า Home**: สไลด์แบนเนอร์ เวลาเปิด เบอร์ เมนูทั้งหมด ปุ่มสมาชิก<br>👀 **เมนูจาก QR** (`menu.html`): สแกนแล้วขึ้นเลขโต๊ะ + เมนู หมดขึ้น "หมด" QR ผิด/บิลปิดขึ้น "หมดอายุ" (อ่าน **token**) (UC-01, 02) | 👀 โชว์**หน่วย** "45฿ / เข่ง" · **ค้นหา + กรองหมวด/ราคา** ทั้งหน้า Home และเมนู QR · footer **ติดต่อ / สมาชิกกลุ่ม / license** | 👀 **ตะกร้า + สั่งอาหาร**: ไม่เกิน 10 ต่อเมนู ของต้องพอ ยังไม่ปิดรับ · แสดงหน่วย<br>👀 **สถานะ** แต่ละรอบ · **ยกเลิกออเดอร์** ที่ครัวยังไม่เริ่ม<br>🧑‍💼 **พนักงานสั่งแทน** มีช่องค้นหา (UC-03–05, 17, 18) | 👀 **หน้าสมาชิก** (ทั้งหน้า): สมัคร/ล็อกอินด้วยเบอร์ + OTP จำลอง · การ์ดสมาชิก + แต้ม + บาร์โค้ด · แท็บ **ประวัติแต้ม** · ได้คูปองต้อนรับอัตโนมัติ · API สมาชิก (คน 5 ค้นตอนปิดบิล) (UC-06–10)<br>👀 แท็บ **คูปองของฉัน**: **โชว์**คูปองที่ลูกค้ามี<br>👀 **หน้า Home**: แถบโปรโมชันดึงคูปองที่ใช้ได้มาโชว์ + สไลด์ดึงรูปจากแบนเนอร์ของคน 2 | ⚙️🧩 **รับของ + Invoice**: รับตาม PO กรอกจำนวนจริง วันหมดอายุ แนบรูปใบแจ้งหนี้ → บวกสต็อก · แท็บรอจ่าย กดบันทึกจ่าย (UC-48, 49) |
| **7 Dashboard + ครัว + ทดสอบ** | 📊 **Dashboard**: โต๊ะมีลูกค้า บิลเปิด เมนูปิดขาย พนักงานใช้งาน + ผังโต๊ะย่อ (UC-44)<br>🛠️ **ทดสอบ flow** | 📊 **Dashboard เน้นกราฟ**: โดนัทโต๊ะว่าง/เต็ม แท่งตามโซน เมนูพร้อมขาย/หมดตามหมวด บิลรายชั่วโมง | 👨‍🍳🧩 **จอครัวแยกโซน** (kitchen-service ครัวดับ ลูกค้ายังสั่งได้): เรียงตามเวลา เกิน 15 นาทีขึ้นแดง · รอ → ทำ → พร้อม → เสิร์ฟ · จำนวน + หน่วย · ยกเลิกรายการพร้อมเหตุผล<br>👨‍🍳 **ยอดเตรียมวันนี้** (UC-20–22, 25) | 📊 **การ์ดห้อง VIP วันนี้** แบบกราฟไทม์ไลน์ 10–20 น. + ยังไม่รับมัดจำ/เลยเวลานัด<br>🛠️ **ทดสอบ** | 📊 **Dashboard เต็ม** แบบกราฟ: ยอดขายวันนี้ รายชั่วโมง Top 5 เมนู ใกล้หมด · วัตถุดิบต่ำ (เรียก inventory ถ้าดับขึ้น "ไม่พร้อมใช้") (UC-60)<br>🛠️ **ทดสอบรอบสุดท้าย** + checklist + ซ้อมสาธิตปิด service |

**Microservices ตาม Feedback:** โค้ดที่ใช้ร่วมกัน (shared) อยู่ใน `lib/` ทุก service ใช้ร่วม · notify-service เป็นการ**จำลอง** ไม่ส่ง SMS/LINE จริง (OTP แสดงบนจอ) · รายละเอียดใน `docs/prompt_เขียนโค้ด/00_อ่านก่อน.md` และ `docs/API_ร้านติ่มซำ_v5.md` ส่วน Microservices
