# วิธีใช้ prompt เขียนโค้ด — ร้านนึ่งสุข (ทีม 7 คน)

ไม่ต้องใช้ prompt Lovable แล้ว ภาพหน้าจอมีแค่ 3–4 หน้าก็พอ หรือไม่มีเลยก็ได้
หน้าตาทุกหน้าจะออกมาเป็น CI เดียวกัน เพราะบังคับให้ใช้ `public/assets/css/style.css` กลาง

## ขั้นตอน (ทำทีละเฟส 1 เฟส = 1 แชต)
1. `git checkout main` → `git pull` → `git checkout -b pX-phaseY` (เช่น `p3-phase1`)
2. เปิดไฟล์ของตัวเองในโฟลเดอร์นี้ → copy **ทั้งกล่องของเฟสนั้น** (ตั้งแต่ ``` ถึง ```)
3. เปิดแชตใหม่ Claude / ChatGPT → แนบไฟล์ตามรายการในหัวไฟล์ + ภาพหน้าจอ (ถ้ามี) → วางกล่อง
4. วางไฟล์ที่ได้ตาม path → `npm run dev` → ทดสอบตามที่ AI บอก
5. `git add` **เฉพาะไฟล์ของตัวเอง** → commit → push → เปิด Pull Request เข้า main
6. AI บอกว่าอยากได้ class CSS / คอลัมน์ / API ของคนอื่น → แจ้งในกลุ่ม อย่าแก้เอง

## ต้องใช้งานของเพื่อนที่ยังไม่เสร็จ ทำไง
ส่วนใหญ่แค่ต้องการ **ข้อมูลในตาราง** (เมนู บิล ออเดอร์) → INSERT ลงฐานข้อมูลเอง หรือรอ `scripts/seed.sql` ของคนที่ 1
ถ้าต้องเรียก **API หรือเปิดหน้า** ของเพื่อนจริงๆ → ทำไฟล์จำลองใน `dev-mocks/` (ดู `dev-mocks/README.md`)
