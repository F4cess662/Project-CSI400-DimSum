# ไฟล์ส่วนกลางของโปรเจกต์ร้านนึ่งสุข (แนบให้บอต)

ไฟล์นี้รวมโค้ดส่วนกลางทั้งหมดของโปรเจกต์ไว้ในที่เดียว ใช้อ้างอิงตอนเขียนโค้ด
ทุกไฟล์ด้านล่างมีอยู่ในโปรเจกต์แล้ว **ห้ามแก้และห้ามเขียนใหม่** ให้เรียกใช้ตามที่มี
ไฟล์แต่ละไฟล์ขึ้นต้นด้วยหัวข้อ `## ไฟล์: <path>`
ระบบเป็น Microservices: API ของครัว/คลังสินค้า/แจ้งเตือน เขียนใน `services/<service>/routes/` (ดูส่วน Microservices ในเอกสาร API)
ฐานข้อมูลอยู่ในไฟล์เดียว `database/dimsum_full.sql` (ส่วนที่ 1 โครงตาราง · ส่วนที่ 2–4 ข้อมูลตัวอย่าง)

## สิ่งที่เปลี่ยนจากเอกสาร API ฉบับก่อน

- ใช้ **Node.js + Express** ชื่อ API เป็น `/api/xxx` ไฟล์อยู่ที่ `routes/xxx.js`
- อ้างอิงเลข **FR ใน Requirement v5** แทนเลข use case
- **เมนูมีโซนครัว** (`kitchen_zone`) จอครัวแยกตามโซนได้
- **ห้อง VIP ขนาดเดียว** 15 คน ยอดขั้นต่ำ 3,000฿ มัดจำ 50% สูงสุด 4 ชั่วโมง (ค่าเหล่านี้อยู่ในตั้งค่าร้าน)
- **ตัด QR รับแต้ม**: กรอกเบอร์สมาชิกตอนปิดบิลได้แต้มทันที ไม่กรอกไม่ได้แต้ม
- **คูปองกำหนดวันในสัปดาห์และยกเว้นวันหยุดราชการได้** + API วันหยุดราชการ
- ตอนดูยอดก่อนจ่าย ระบบแนะนำคูปองที่ใช้ได้ตอนนั้น
- แบ่งเป็น **4 เฟส** และมีคอลัมน์ **คนทำ** ตามตารางแบ่งงานใน Requirement v5

## ข้อตกลงที่ใช้ทุก API

- หน้าเว็บเรียกด้วย `fetch('/api/ชื่อapi')` ไฟล์ใน `routes/` ถูกโหลดอัตโนมัติ ไม่ต้องแก้ `server.js`
- อ่านข้อมูล = `GET` ส่งค่าทาง URL เช่น `?q=ฮะ`
- เพิ่ม แก้ ลบ และอื่นๆ = `POST` ส่ง JSON ที่มี `action` เช่น `{"action":"create", ...}` (ถ้ามีไฟล์รูปใช้ form-data)
- คำตอบทุก API: `{"success": true/false, "data": ..., "message": ""}`
- ชื่อฟิลด์ใน JSON ตรงกับชื่อในฐานข้อมูลเป๊ะ (snake_case)
- พนักงานล็อกอินด้วย session / สมาชิกใช้ session แยก / ลูกค้า walk-in ใช้ `token` จาก QR บิล
- หน้าที่ต้องอัปเดตเอง (จอครัว, ผังโต๊ะ, สถานะของลูกค้า) เรียก GET ซ้ำทุก 5–10 วินาที ไม่ต้องทำ real-time
- ทุก API ที่เปลี่ยนข้อมูลสำคัญ เรียก `writeLog()`

**ใครเรียกได้**: สาธารณะ = ไม่ต้องล็อกอิน · พนักงาน = ทุกบทบาทที่ล็อกอิน · staff+ = พนักงานหน้าร้าน ผู้จัดการ เจ้าของร้าน · manager+ = ผู้จัดการ เจ้าของร้าน · [รับเงิน] / [จอง VIP] = staff ต้องมีช่องติ๊กนั้น (ผู้จัดการและเจ้าของร้านทำได้เสมอ)

**เฟส**: P1 ฐานระบบ · P2 สั่งอาหาร ครัว ชำระเงิน · P3 ห้อง VIP สมาชิก แต้ม คูปอง · P4 ผู้จัดการ จัดซื้อ สต็อก

## Microservices

ระบบหลัก (port 3000) เป็น **API Gateway**: หน้าเว็บเรียก `/api/...` ที่เดียว Gateway ส่งต่อ path ของ service แยกไปยัง port ของมัน
service ดับ → path นั้นตอบ `503 "ระบบ...ขัดข้องชั่วคราว ส่วนอื่นของร้านยังใช้งานได้"` ส่วนอื่นทำงานต่อ (Fault Isolation)

| service | port | path ที่ Gateway ส่งต่อ | ไฟล์ API | ตารางที่ใช้ได้ |
| --- | --- | --- | --- | --- |
| main (Gateway) | 3000 | ที่เหลือทั้งหมด | `routes/*.js` | ทุกตาราง ยกเว้นตารางคลังและ notifications |
| kitchen | 4001 | /api/kitchen | `services/kitchen/routes/kitchen.js` | orders, order_items, menu_items, bills, bill_tables, dining_tables, vip_rooms (ฐานข้อมูลร่วม) |
| inventory | 4002 | /api/ingredients, suppliers, purchase_orders, goods_receipts, stock | `services/inventory/routes/<api>.js` | ingredients, suppliers, supplier_prices, purchase_orders, purchase_order_items, goods_receipts, stock_movements |
| notify | 4003 | /api/notifications | `services/notify/routes/notifications.js` + `worker.js` | notifications |

**คิวงาน (topic)**

| topic | ใครส่ง (publish) | ใครรับ (consume) | payload |
| --- | --- | --- | --- |
| notify | members (OTP, สมัคร) · vip_bookings (จอง, รับมัดจำ) · purchase_orders (ส่ง PO) · ingredients/stock (ใกล้หมด) | notify-service | `{ channel: 'sms'\|'line'\|'system', to, title, message }` |

ข้อจำกัด: ทุก service ใช้ฐานข้อมูล MySQL ก้อนเดียว (XAMPP) แต่แบ่งสิทธิ์ใช้ตารางตามตารางบน · ระบบจริงจะแยกฐานข้อมูลต่อ service (Database per Service)

-- ===== Microservices (ระบบหลัก + ครัว + คลังสินค้า + แจ้งเตือน ใช้ร่วมกัน) =====
-- 3 ตารางนี้ server สร้างให้เองตอนเปิดถ้ายังไม่มี (CREATE TABLE IF NOT EXISTS) ไม่ import ก็ใช้ได้

-- session ล็อกอินที่ทุก service อ่านร่วมกัน (lib/session.js)
CREATE TABLE IF NOT EXISTS sessions (
  sid     VARCHAR(128) NOT NULL PRIMARY KEY,
  data    MEDIUMTEXT   NOT NULL,
  expires BIGINT       NOT NULL,
  KEY idx_sessions_expires (expires)
) ENGINE=InnoDB;

-- Message Queue "แท่นเสียบบิล" (lib/queue.js) · topic ดูใน docs/API ส่วน Microservices
CREATE TABLE IF NOT EXISTS event_queue (
  id         BIGINT AUTO_INCREMENT PRIMARY KEY,
  topic      VARCHAR(50)  NOT NULL,
  payload    LONGTEXT     NOT NULL,
  status     ENUM('pending','processing','done','failed') NOT NULL DEFAULT 'pending',
  attempts   INT          NOT NULL DEFAULT 0,
  last_error VARCHAR(255) NULL,
  locked_by  VARCHAR(64)  NULL,
  locked_at  DATETIME     NULL,
  created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  done_at    DATETIME     NULL,
  KEY idx_queue_pick (topic, status, id)
) ENGINE=InnoDB;

-- ประวัติข้อความที่ notify-service ส่ง (SMS/LINE จำลอง) — ตารางของ notify-service เท่านั้น
CREATE TABLE IF NOT EXISTS notifications (
  id         BIGINT AUTO_INCREMENT PRIMARY KEY,
  event_id   BIGINT       NULL,
  channel    ENUM('sms','line','system') NOT NULL DEFAULT 'system',
  recipient  VARCHAR(100) NULL,
  title      VARCHAR(150) NULL,
  message    TEXT         NOT NULL,
  status     ENUM('sent','failed') NOT NULL DEFAULT 'sent',
  created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_notifications_time (created_at)
) ENGINE=InnoDB;

async function query(sql, params = []) {

  return rows;

  return rows[0] || null;

/**
 * ทำหลายคำสั่งแบบทั้งหมดหรือไม่ทำเลย เช่น เปิดบิล + เปลี่ยนสถานะโต๊ะ
 * await transaction(async (conn) => { await conn.execute(...); await conn.execute(...); })
 */
async function transaction(work) {
  const conn = await pool.getConnection();
  try {
    await conn.beginTransaction();
    const result = await work(conn);
    await conn.commit();
    return result;
  } catch (err) {
    await conn.rollback();
    throw err;
  } finally {
    conn.release();
  }
}

// รูปแบบคำตอบกลางของทุก API: {"success": true/false, "data": ..., "message": ""}

class ApiError extends Error {
  constructor(message, status = 400, data = null) {
    super(message);
    this.status = status;
    this.data = data;
  }
}

/** ตอบสำเร็จ: return ok(res, data, 'ข้อความ') */
function ok(res, data = null, message = '') {
  return res.json({ success: true, data, message });
}

/** ตอบไม่สำเร็จ: throw fail('ข้อความ', 403) — ใช้ throw เพื่อหยุดทำงานทันที */
function fail(message, status = 400, data = null) {
  return new ApiError(message, status, data);
}

/** ตรวจว่าส่งข้อมูลครบ ไม่ครบโยน error 422 ทันที: requireFields(req.body, ['name','price']) */
function requireFields(body, fields) {
  const missing = fields.filter((f) => body[f] === undefined || body[f] === null || body[f] === '');
  if (missing.length) throw fail('ข้อมูลไม่ครบ: ' + missing.join(', '), 422);
  return body;
}

/** ห่อ handler แบบ async ให้ error ทุกชนิดไปถึงตัวจัดการ error กลาง */
const handle = (fn) => (req, res, next) => Promise.resolve(fn(req, res, next)).catch(next);

/** ตัวจัดการ error กลาง (อยู่ท้ายสุดใน server.js) ตอบเป็น JSON เสมอ */
function errorHandler(err, req, res, next) {
  if (err instanceof ApiError) {
    return res.status(err.status).json({ success: false, data: err.data, message: err.message });
  }
  console.error(err);
  return res.status(500).json({ success: false, data: null, message: 'เกิดข้อผิดพลาดในระบบ: ' + err.message });
}

module.exports = { ApiError, ok, fail, requireFields, handle, errorHandler };

/**
 * Message Queue อย่างง่าย (เก็บในตาราง event_queue ของ MySQL ไม่ต้องลง Redis/Kafka)
 * เปรียบเหมือน "แท่นเสียบบิล": คนส่งเสียบงานไว้แล้วไปทำอย่างอื่นต่อ service ปลายทางค่อยมาหยิบไปทำ
 * ถ้า service ปลายทางดับอยู่ งานยังรออยู่ในคิว พอเปิดกลับมาก็ทำต่อจนครบ ไม่หาย
 *
 *   const { publish, consume } = require('../lib/queue');
 *   await publish('notify', { channel: 'sms', to: '0812345678', message: 'รหัส OTP 123456' });
 *   await publish('notify', {...}, conn);           // ใส่ conn เมื่ออยู่ใน transaction() → งานเข้าคิวพร้อมกับข้อมูลหลัก
 *   consume('notify', async (payload, event) => { ... });   // ใช้ใน service ปลายทาง (throw = ลองใหม่ภายหลัง)
 *
 * หัวข้อ (topic) ที่ตกลงกันไว้ดูใน docs/API_ร้านติ่มซำ_v5.md ส่วน Microservices
 */
const crypto = require('crypto');
const { query } = require('./db');

const MAX_ATTEMPTS = 5;
const STUCK_SECONDS = 60; // งานที่ค้าง processing นานเกินนี้ (service ดับกลางคัน) จะถูกหยิบใหม่

const CREATE_SQL = `CREATE TABLE IF NOT EXISTS event_queue (
    id         BIGINT AUTO_INCREMENT PRIMARY KEY,
    topic      VARCHAR(50)  NOT NULL,
    payload    LONGTEXT     NOT NULL,
    status     ENUM('pending','processing','done','failed') NOT NULL DEFAULT 'pending',
    attempts   INT          NOT NULL DEFAULT 0,
    last_error VARCHAR(255) NULL,
    locked_by  VARCHAR(64)  NULL,
    locked_at  DATETIME     NULL,
    created_at DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    done_at    DATETIME     NULL,
    KEY idx_queue_pick (topic, status, id)
  ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci`;

// สร้างตารางให้เองครั้งแรกที่ใช้ (ถ้าฐานข้อมูลยังไม่เปิด จะลองใหม่ครั้งถัดไป)
let created = null;
function ready() {
  if (!created) created = query(CREATE_SQL).catch((err) => { created = null; throw err; });
  return created;
}

/** เสียบงานเข้าคิว คืน id ของงาน · conn = connection จาก transaction() (ไม่ใส่ก็ได้) */
async function publish(topic, payload, conn = null) {
  await ready();
  const sql = 'INSERT INTO event_queue (topic, payload) VALUES (?, ?)';
  const params = [topic, JSON.stringify(payload ?? {})];
  if (conn) {
    const [res] = await conn.execute(sql, params);
    return res.insertId;
  }
  const res = await query(sql, params);
  return res.insertId;
}

/** หยิบงาน 1 ชิ้นของ topic นี้มาจองไว้ (ไม่ซ้ำกันแม้มีหลายตัวหยิบพร้อมกัน) */
async function claim(topic) {
  const token = crypto.randomBytes(12).toString('hex');
  const res = await query(
    `UPDATE event_queue
        SET status = 'processing', locked_by = ?, locked_at = NOW(), attempts = attempts + 1
      WHERE topic = ?
        AND (status = 'pending' OR (status = 'processing' AND locked_at < NOW() - INTERVAL ${STUCK_SECONDS} SECOND))
      ORDER BY id
      LIMIT 1`, [token, topic]);
  if (!res.affectedRows) return null;
  const rows = await query("SELECT * FROM event_queue WHERE locked_by = ? AND status = 'processing'", [token]);
  return rows[0] || null;
}

/**
 * ให้ service ปลายทางหยิบงานไปทำเรื่อยๆ
 * handler(payload, event) ทำสำเร็จ = done · throw = ลองใหม่ (ครบ 5 ครั้ง = failed ให้เจ้าของร้านกดลองใหม่ที่หน้าสถานะระบบ)
 */
function consume(topic, handler, { everyMs = 1000 } = {}) {
  let stopped = false;
  (async function loop() {
    await ready();
    while (!stopped) {
      let event = null;
      try {
        event = await claim(topic);
        if (!event) { await sleep(everyMs); continue; }
        await handler(JSON.parse(event.payload), event);
        await query("UPDATE event_queue SET status = 'done', done_at = NOW(), last_error = NULL WHERE id = ?", [event.id]);
      } catch (err) {
        if (event) {
          const status = event.attempts >= MAX_ATTEMPTS ? 'failed' : 'pending';
          await query('UPDATE event_queue SET status = ?, last_error = ?, locked_by = NULL WHERE id = ?',
            [status, String(err.message || err).slice(0, 255), event.id]).catch(() => {});
        } else {
          console.error(`คิว ${topic}:`, err.message);
        }
        await sleep(everyMs);
      }
    }
  })();
  return () => { stopped = true; };
}

/** สรุปจำนวนงานในคิว แยกตาม topic และสถานะ (ใช้ในหน้าสถานะระบบ) */
async function queueStats() {
  await ready();
  const rows = await query('SELECT topic, status, COUNT(*) AS n FROM event_queue GROUP BY topic, status ORDER BY topic');
  const byTopic = {};
  for (const r of rows) {
    byTopic[r.topic] = byTopic[r.topic] || { topic: r.topic, pending: 0, processing: 0, done: 0, failed: 0 };
    byTopic[r.topic][r.status] = r.n;
  }
  return Object.values(byTopic);
}

/** ส่งงานที่ failed กลับเข้าคิวใหม่ */
async function retryFailed(topic = null) {
  await ready();
  const res = await query(
    `UPDATE event_queue SET status = 'pending', attempts = 0, locked_by = NULL
      WHERE status = 'failed' ${topic ? 'AND topic = ?' : ''}`, topic ? [topic] : []);
  return res.affectedRows;
}

const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

/**
 * API Gateway — server หลักส่งต่อคำขอไปยัง service ที่ถูกต้อง (ดูรายการใน config.services)
 * เปรียบเหมือนพนักงานต้อนรับ: ลูกค้าคุยกับหน้าร้านที่เดียว หน้าร้านส่งต่อให้สเตชันที่รับผิดชอบ
 * ถ้า service ปลายทางดับ ตอบ 503 "ระบบ...ขัดข้องชั่วคราว" เฉพาะส่วนนั้น ส่วนอื่นของร้านยังใช้ได้ (Fault Isolation)
 */
const http = require('http');
const config = require('../config');
const { ApiError } = require('./response');

const serviceUrl = (name) => {
  const s = config.services[name];
  return `http://${s.host || config.serviceHost}:${s.port}`;
};

/** middleware ส่งต่อคำขอทั้งก้อน (รวม cookie และไฟล์อัปโหลด) ไปยัง service */
function proxyTo(name) {
  const svc = config.services[name];
  const target = new URL(serviceUrl(name));
  return (req, res) => {
    const upstream = http.request({
      hostname: target.hostname,
      port: target.port,
      method: req.method,
      path: req.originalUrl,
      headers: { ...req.headers, host: target.host, 'x-forwarded-for': req.socket.remoteAddress || '' },
    }, (r) => {
      res.writeHead(r.statusCode, r.headers);
      r.pipe(res);
    });
    upstream.setTimeout(15000, () => upstream.destroy(new Error('timeout')));
    upstream.on('error', () => {
      if (res.headersSent) return res.end();
      res.status(503).json({ success: false, data: null, message: `ระบบ${svc.label}ขัดข้องชั่วคราว ส่วนอื่นของร้านยังใช้งานได้` });
    });
    req.pipe(upstream);
  };
}

/** ผูก path ของทุก service เข้ากับ server หลัก (เรียกก่อน express.json) */
function mountServices(app) {
  for (const [name, svc] of Object.entries(config.services)) {
    for (const p of svc.paths) app.use('/api/' + p, proxyTo(name));
  }
}

/** ยิง GET แบบมีเวลาจำกัด คืน { status, body } */
function getJson(url, ms, headers = {}) {
  return new Promise((resolve, reject) => {
    const req = http.get(url, { headers }, (r) => {
      let raw = '';
      r.on('data', (c) => { raw += c; });
      r.on('end', () => {
        try { resolve({ status: r.statusCode, body: JSON.parse(raw || '{}') }); } catch (e) { reject(e); }
      });
    });
    req.setTimeout(ms, () => req.destroy(new Error('timeout')));
    req.on('error', reject);
  });
}

/** เช็กว่าแต่ละ service ยังทำงานอยู่ไหม (หน้าสถานะระบบ) */
async function checkServices() {
  return Promise.all(Object.entries(config.services).map(async ([name, svc]) => {
    const started = Date.now();
    try {
      const { body } = await getJson(serviceUrl(name) + '/health', 1500);
      return { name, label: svc.label, port: svc.port, paths: svc.paths, up: true, ms: Date.now() - started, uptime: body.data && body.data.uptime };
    } catch {
      return { name, label: svc.label, port: svc.port, paths: svc.paths, up: false, ms: null, uptime: null };
    }
  }));
}

/**
 * เรียก API ของ service อื่นจากฝั่ง server (service คุยกันผ่าน API ไม่อ่านตารางของกันและกัน)
 *   const low = await callService(req, 'inventory', '/api/ingredients?low_stock=1');
 * ส่ง cookie ของผู้ใช้ต่อให้ จึงเช็กสิทธิ์ได้ตามปกติ · service ดับ → throw 503 (ให้ catch แล้วแสดง "ไม่พร้อมใช้")
 */
function callService(req, name, path, { method = 'GET', body = null, timeoutMs = 3000 } = {}) {
  const svc = config.services[name];
  const target = new URL(serviceUrl(name));
  const payload = body ? JSON.stringify(body) : null;
  return new Promise((resolve, reject) => {
    const r = http.request({
      hostname: target.hostname,
      port: target.port,
      method,
      path,
      headers: {
        cookie: (req && req.headers.cookie) || '',
        ...(payload ? { 'content-type': 'application/json', 'content-length': Buffer.byteLength(payload) } : {}),
      },
    }, (resp) => {
      let raw = '';
      resp.on('data', (c) => { raw += c; });
      resp.on('end', () => {
        let json;
        try { json = JSON.parse(raw); } catch { return reject(new ApiError(`ระบบ${svc.label}ตอบกลับไม่ถูกต้อง`, 502)); }
        if (!json.success) return reject(new ApiError(json.message || `ระบบ${svc.label}ตอบกลับผิดพลาด`, resp.statusCode));
        resolve(json.data);
      });
    });
    r.setTimeout(timeoutMs, () => r.destroy(new Error('timeout')));
    r.on('error', () => reject(new ApiError(`ระบบ${svc.label}ขัดข้องชั่วคราว`, 503)));
    if (payload) r.write(payload);
    r.end();
  });
}

module.exports = { mountServices, checkServices, callService, serviceUrl };

/**

 * - ถ้ามี services/<ชื่อ>/worker.js จะถูกเรียกตอนเริ่ม (ใช้ consume() รับงานจากคิว)
 * - service นี้ดับ → เฉพาะส่วนนี้ใช้ไม่ได้ server หลักและ service อื่นยังทำงานต่อ
 */
const express = require('express');
const fs = require('fs');
const path = require('path');
const config = require('../config');
const { sessionMiddleware } = require('./session');
const { errorHandler } = require('./response');
const { mustBe } = require('./auth');

function startService({ name, dir }) {
  const svc = config.services[name];
  if (!svc) throw new Error(`ไม่พบ service "${name}" ใน config.services`);

  const app = express();
  app.use(express.json());
  app.use(express.urlencoded({ extended: true }));
  app.use(sessionMiddleware());

  const startedAt = Date.now();
  app.get('/health', (req, res) => res.json({
    success: true,
    data: { service: name, uptime: Math.round((Date.now() - startedAt) / 1000), pid: process.pid },
    message: '',
  }));

  // ปุ่ม "ปิด service (สาธิต)" ในหน้าสถานะระบบ — เจ้าของร้านเท่านั้น
  // รันด้วย npm run start:all แล้ว service จะถูกเปิดกลับเองภายในไม่กี่วินาที
  app.post('/health/crash', async (req, res, next) => {
    try {
      await mustBe(req, ['owner']);
      res.json({ success: true, data: null, message: `ปิดระบบ${svc.label}แล้ว (สาธิต)` });
      console.log(`[${name}] ถูกสั่งปิดเพื่อสาธิต`);
      setTimeout(() => process.exit(1), 200);
    } catch (err) { next(err); }
  });

  const routesDir = path.join(dir, 'routes');
  const loaded = [];
  if (fs.existsSync(routesDir)) {
    for (const file of fs.readdirSync(routesDir)) {
      if (!file.endsWith('.js') || file.startsWith('_')) continue;
      const route = file.replace(/\.js$/, '');
      if (!svc.paths.includes(route)) {
        console.warn(`[${name}] ข้าม routes/${file}: "${route}" ไม่อยู่ใน config.services.${name}.paths (Gateway จะไม่ส่งมาที่นี่)`);
        continue;
      }
      app.use('/api/' + route, require(path.join(routesDir, file)));
      loaded.push(route);
    }
  }

  app.use('/api', (req, res) => res.status(404).json({ success: false, data: null, message: 'ไม่พบ API นี้' }));
  app.use(errorHandler);

  const worker = path.join(dir, 'worker.js');
  if (fs.existsSync(worker)) require(worker);

  app.listen(svc.port, () => {
    console.log(`[${name}] ระบบ${svc.label} ทำงานที่ port ${svc.port} · API: ${loaded.map((r) => '/api/' + r).join(', ') || '(ยังไม่มี route)'}`);
  });
  return app;
}

module.exports = { startService };

 * /api/auth — ล็อกอิน / ออกจากระบบ / ผู้ใช้ปัจจุบัน (UC-00)
 * POST {"action":"login","username":"...","password":"..."}
 * POST {"action":"logout"}
 * GET  → ข้อมูลผู้ใช้ที่ล็อกอินอยู่ (ใช้สร้าง sidebar ตามบทบาท)
 */
const router = require('express').Router();
const bcrypt = require('bcryptjs');
const { queryOne } = require('../lib/db');
const { ok, fail, requireFields, handle } = require('../lib/response');
const { requireLogin, loginUser, logoutUser, loadUser } = require('../lib/auth');
const { writeLog } = require('../lib/log');

router.get('/', requireLogin, handle(async (req, res) => ok(res, req.user)));

router.post('/', handle(async (req, res) => {
  const b = req.body;
  switch (b.action) {
    case 'login': {
      requireFields(b, ['username', 'password']);
      const u = await queryOne('SELECT id, password_hash, is_active FROM users WHERE username = ?',
        [String(b.username).trim()]);
      if (!u || !(await bcrypt.compare(String(b.password), u.password_hash))) {
        throw fail('ชื่อล็อกอินหรือรหัสผ่านไม่ถูกต้อง', 401);
      }
      if (u.is_active !== 1) throw fail('บัญชีนี้ถูกปิดการใช้งาน', 403);
      await loginUser(req, u.id);
      await writeLog(req, 'user.login', 'users', u.id);
      return ok(res, await loadUser(req), 'ล็อกอินสำเร็จ');
    }
    case 'logout': {
      if (await loadUser(req)) await writeLog(req, 'user.logout', 'users', req.user.id);
      logoutUser(req);
      return ok(res, null, 'ออกจากระบบแล้ว');
    }
    default:
      throw fail('ไม่รู้จัก action นี้', 400);
  }
}));

/* =========================================================
   api.js กลาง — ทุกหน้าใช้ไฟล์นี้ ห้ามเขียน fetch เองในหน้า
   ห้ามแก้เอง ถ้าต้องการฟังก์ชันเพิ่ม แจ้งคนที่ 1
   ========================================================= */

const api = {
  /** อ่านข้อมูล: const menus = await api.get('menus', { q: 'ฮะ' }) → ได้ data เลย */
  async get(name, params = {}) {
    const qs = new URLSearchParams(Object.entries(params).filter(([, v]) => v !== undefined && v !== null && v !== ''));
    return api._send('/api/' + name + (qs.toString() ? '?' + qs : ''), { method: 'GET' });
  },
  /** เปลี่ยนข้อมูล: await api.post('bills', { action: 'open', table_ids: [5], guests: 4 }) */
  async post(name, body = {}) {
    return api._send('/api/' + name, {
      method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(body),
    });
  },
  /** ส่งไฟล์รูป: const fd = new FormData(form); fd.append('action','create'); await api.upload('menus', fd) */
  async upload(name, formData) {
    return api._send('/api/' + name, { method: 'POST', body: formData });
  },
  async _send(url, opts) {
    let json;
    try {
      const res = await fetch(url, opts);
      json = await res.json();
      if (res.status === 401 && location.pathname.startsWith('/admin/') && !location.pathname.endsWith('login.html')) {
        location.href = '/admin/login.html';
      }
    } catch (e) {
      json = { success: false, data: null, message: 'เชื่อมต่อเซิร์ฟเวอร์ไม่ได้' };
    }
    if (!json.success) {
      const err = new Error(json.message || 'เกิดข้อผิดพลาด');
      err.data = json.data;
      throw err;
    }
    api.lastMessage = json.message;
    return json.data;
  },
};

/** เรียก API แล้วแสดง toast ให้อัตโนมัติ: await run(() => api.post(...), 'บันทึกแล้ว') → คืน data หรือ null ถ้า error */
async function run(fn, successText) {
  try {
    const data = await fn();
    const msg = successText || api.lastMessage;
    if (msg) toast(msg);
    return data;
  } catch (e) {
    toast(e.message, 'error');
    return null;
  }
}

/** เปิด modal: const m = openModal({ title, body: '<html>', size: 'lg', footer: '<button>...' }); m.close() */
function openModal({ title = '', body = '', footer = '', size = '' }) {
  const bg = document.createElement('div');
  bg.className = 'modal-backdrop';
  bg.innerHTML = `
    <div class="modal ${size === 'lg' ? 'modal-lg' : ''}" role="dialog">
      <div class="modal-head"><h3>${title}</h3><button class="btn btn-ghost btn-icon btn-sm" data-close>✕</button></div>
      <div class="modal-body">${body}</div>
      ${footer ? `<div class="modal-foot">${footer}</div>` : ''}
    </div>`;
  const close = () => bg.remove();
  bg.addEventListener('click', (e) => { if (e.target === bg || e.target.closest('[data-close]')) close(); });
  document.body.appendChild(bg);
  return { el: bg.querySelector('.modal'), close };
}

/** ถามยืนยัน: if (await confirmModal('ยกเลิกโต๊ะ T08?', 'ยืนยัน', true)) { ... } */

  return new Promise((resolve) => {

      title: 'ยืนยัน',
      body: `<p>${message}</p>`,
      footer: `<button class="btn btn-secondary" data-close>ยกเลิก</button>

    });
    m.el.querySelector('[data-ok]').onclick = () => { m.close(); resolve(true); };
    m.el.parentElement.addEventListener('click', (e) => { if (e.target.closest('[data-close]') || e.target === m.el.parentElement) resolve(false); });
  });
}

function canSee(user, item) {
  if (!item.roles.includes(user.role_code)) return false;
  if (item.perm && user.role_code === 'staff') {
    return item.perm === 'payment' ? user.can_payment === 1 : user.can_vip_booking === 1;
  }
  return true;
}

/** สถานะร้านจาก settings → { open, text } */
function shopStatus(s) {
  const now = new Date().toTimeString().slice(0, 8);
  if (now >= s.morning_open && now < s.morning_close)
    return { open: true, text: `เปิดอยู่ · กะเช้า · ปิดรับออเดอร์ ${s.morning_last_order.slice(0, 5)}` };
  if (now >= s.evening_open && now < s.evening_close)
    return { open: true, text: `เปิดอยู่ · กะเย็น · ปิดรับออเดอร์ ${s.evening_last_order.slice(0, 5)}` };
  return { open: false, text: 'ปิดอยู่' };
}

async function initStaffPage({ title, roles, perm } = {}) {
  let user;
